One original line: the GPS's own excuse for sending the driver down the
wrong road. The GPS is smug and defensive, blaming the map — it rerouted
the driver through a wedding because the map promised it cake, and unlike
the map, it keeps its promises. A fresh, specific detail (a wedding, and
cake) instead of the usual recalculating joke, with a turn the reader does
not see coming.

Run `python3 main.py` to write the entry to `/output/entry.txt`
(one line, 111 characters including the trailing newline — inside the
gate's 1–200 character limit).
